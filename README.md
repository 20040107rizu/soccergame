# マイクラブ・マスターズ（仮）

スマホで遊べるサッカークラブ育成・経営ゲーム。ウイニングイレブンの「マスターリーグ」をイメージして、
弱小クラブを移籍とポイント運用で強くしていく。

- **形式**：PWA（ブラウザで動作。ホーム画面に追加するとアプリのように使える。オフライン対応）
- **試合**：監督視点。テキスト実況＋ミニピッチのハイライト
- **データ**：端末内に自動セーブ（3スロット）＋ JSON ファイルでのバックアップ・引き継ぎ
- **エディット**：選手作成・能力・見た目・所属の編集、クラブ名とカラーの編集、名簿 CSV の一括編集

## 遊ぶ

**https://20040107rizu.github.io/soccergame/** をスマホで開く（ホーム画面に追加するとアプリのように使える）。
ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）が自動でテスト・ビルドして公開する。

## 開発

```bash
npm install
npm run dev      # 開発サーバー（同じWi-Fiのスマホから http://<PCのIP>:5173 で確認できる）
npm test         # ゲームロジックのテスト（3シーズン自動進行など）
npm run build    # dist/ に本番ビルド
```

## いまの仕組み（v0.1）

| 項目 | 内容 |
| --- | --- |
| リーグ | 8クラブ・ホーム＆アウェー（全14節） |
| ポイント収入 | 勝利 1500 / 引分 800 / 敗戦 400、シーズン終了時に順位ボーナス（1位 12000 〜 8位 1500） |
| ポイント支出 | 移籍金、契約延長の契約金、シーズン終了時に全選手の年俸 |
| 移籍金 | フリー選手＝評価額の25%、他クラブ所属＝評価額の115%＋残り契約年数×5% |
| 放出 | 評価額の70%を受け取る。登録は16〜30人 |
| 成長 | 試合出場で少しずつ成長。シーズン終了時に年齢・成長タイプ（早熟/標準/晩成）・出場数に応じて伸びる/衰える |
| 契約 | 残り年数が0になると退団（延長はポイントが必要）。人数が16人を割るとユースから昇格 |
| 引退 | 34歳以上で確率的に引退。毎シーズン、新人とベテランがフリー市場に追加 |

## 構成

```
src/game/      ゲームロジック（UIに依存しない）
  types.ts       データ型（選手・クラブ・日程・セーブ全体）
  rating.ts      総合値・ポジション適性・評価額・フォーメーション
  match.ts       試合シミュレーションと実況イベント
  season.ts      日程・順位表・節の進行・シーズン終了処理
  transfer.ts    獲得・放出・契約延長
  save.ts        セーブ/ロード/書き出し
  roster.ts      名簿CSVの入出力
src/screens/   画面（タイトル/ホーム/チーム編成/移籍/リーグ/エディット/試合）
src/components 顔アバター・共通UI
```

## 実在選手について

初期データは架空のクラブ・選手。エディット画面か「名簿CSV」（全選手を書き出し → スプレッドシートで名前などを書き換え →
読み込み）で好きな選手名に置き換えられる。実名データを含めたまま一般公開する場合は肖像権・ライセンスに注意。
