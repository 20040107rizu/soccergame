# マスターリーグ

スマホで遊べるサッカークラブ育成・経営ゲーム。ウイニングイレブンの「マスターリーグ」をイメージして、
プレミアリーグのクラブ（またはオリジナルチーム）を率い、移籍の駆け引きと采配でクラブを頂点へ導く。

## 遊ぶ

**https://20040107rizu.github.io/soccergame/** をスマホで開く（ホーム画面に追加するとアプリのように使える）。
ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）が自動でテスト・ビルドして公開する。

## 主な機能（v0.2）

| 項目 | 内容 |
| --- | --- |
| クラブ選択 | 2026-27 プレミアリーグ全 20 クラブ＋オリジナルチーム（1 クラブと入れ替えて参戦） |
| 選手データ | PL 20 クラブ＋CL 出場 31 クラブの実在選手（約 1,100 人）。所属は 2026-27 開幕時点、能力値は推定 |
| 能力値 | eFootball 準拠の 25 項目＋逆足頻度/精度・コンディション安定度・ケガ耐性、プレースタイル、特殊スキル |
| ポジション | 13 ポジション。選手詳細でヒートマップ表示（メイン / 適性 / 可） |
| 調子 | 5 段階の矢印（⬆ターコイズ ↖緑 ⬅黄 ↙オレンジ ⬇赤）。試合の能力に影響 |
| 大会 | プレミアリーグ 38 節＋チャンピオンズリーグ（36 クラブのリーグフェーズ → プレーオフ → ラウンド16 → 決勝） |
| 試合 | 1 分ずつ進むテキスト実況＋ミニピッチ。一時停止して交代（5 人）・作戦・フォーメーション変更。体力・負傷・退場あり |
| 試合前 | チーム画面と同じ編成画面で最終確認してからキックオフ |
| 移籍 | 夏（開幕〜第 4 節前）と冬（第 20〜23 節前）の移籍期間のみ。①クラブと移籍金交渉 → ②選手と契約交渉（クラブの格・CL・出場機会・愛着で意欲が変わる）。CPU からのオファー、売却打診、契約解除、契約延長 |
| お金 | 移籍資金（€M）と年俸総額の上限。試合賞金・CL ステージ賞金・リーグ分配金 |
| エディット | オリジナルチームの選手のみ：名前・適性・25 能力値・特性・スキル・見た目まで全て編集可能。実在クラブの能力値は編集不可 |
| セーブ | 3 スロットに自動セーブ＋JSON ファイルの書き出し/読み込み |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ゲームロジックのテスト（2 シーズン自動進行・移籍交渉など）
npm run build    # dist/ に本番ビルド
```

## 構成

```
src/data/        実在クラブ・選手の初期データ（1 行 1 選手の文字列）
src/game/        ゲームロジック（UI 非依存）
  types.ts         データ型
  stats.ts         能力値 25 項目・総合値・プレースタイル・特殊スキル・能力値生成
  positions.ts     ポジション座標・フォーメーション・適性補正
  data.ts          初期データの読み込み、架空選手・オリジナルチームの生成
  lineup.ts        スタメン自動選択・入れ替え
  engine.ts        1 分刻みの試合エンジン（交代・作戦・負傷・退場・評価点）
  competitions.ts  カレンダー・PL 日程・CL 組み合わせ・決勝T・順位表
  season.ts        試合日の処理、調子・負傷・成長、CPU の補強、シーズン終了
  transfer.ts      移籍交渉（クラブ・選手）、オファー、契約
  economy.ts       市場価値・年俸・賞金
src/screens/     画面
src/components/  共通 UI（ヒートマップ、編成ボード、調子矢印など）
```

## 実在選手のデータについて

所属は 2026 年 10 月時点の Web 検索結果をもとに作成しています。情報源によって食い違いがあるため、実際と異なる場合があります。
能力値・年齢・プレースタイルは推定値です。実名データを含めて一般公開する場合は肖像権・ライセンスに注意してください。
