# フレンドランキングの設定（最初の1回だけ）

1. Google スプレッドシートで新しいスプレッドシートを作る（名前は「マスターリーグ ランキング」など）。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初から入っているコードを全部消して、`docs/ranking-apps-script.gs` の中身を貼り付け、保存（💾）する。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、アクセスの承認を求められたら自分のアカウントで許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）。
6. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/.../exec`）をコピーして、開発者（Claude）に送る。
7. `src/config.ts` の `RANKING_URL` にその URL を入れてリリースすると、ランキングが動き出す。

スプレッドシートの「ranking」シートに、各プレイヤーの状況が1行ずつ自動で記録される。
