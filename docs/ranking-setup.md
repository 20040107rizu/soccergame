# フレンドランキングの設定（最初の1回だけ）

記録先のスプレッドシート「マスターリーグ ランキング」は作成済み（ID: 1EgfWehzady0eZ_CZG_DYgE_DlheAY88x2gv0_57RcNw）。

1. そのスプレッドシートを開き、メニューの「拡張機能」→「Apps Script」を開く。
2. 最初から入っているコードを全部消して、`docs/ranking-apps-script.gs` の中身を貼り付け、保存（💾）する。
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、アクセスの承認を求められたら自分のアカウントで許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）。
5. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/.../exec`）を `src/config.ts` の `RANKING_URL` に入れてリリースする。

スプレッドシートの最初のシートに、各プレイヤーの状況が1行ずつ自動で記録される。
